## Scope

The facilitator's drawer — additive UI over intents the DO already handles (01.1):
`nudge`, `setGate`, `setSpotlight`. Visible only when the local participant's role is
`facilitator`; the facilitator can still sort as a participant.

### Drawer (`app/src/components/FacilitatorPanel.tsx`)
- Edge drawer (Sheet from 00.3) togglable from a persistent, facilitator-only button
  across sort and wall routes. Focus management per Modal rules; does not obstruct the
  card stack when closed.

### Progress dashboard
- Roster table: per participant — name, avatar, connection status, round + counts
  (`progress` from `SessionState`), "Done ✓". **Never card contents** (the data model
  already makes this impossible pre-reveal; the dashboard also does not render reveal
  snapshot contents — counts and revealed-round badges only, decision). Sortable by
  round progress (decision: single toggle, default join order).

### Nudge
- Text input (≤120 chars, decision) + send → `nudge { text }` → every participant sees
  a gentle, auto-dismissing (8s, decision) banner rendered via Toast at `--z-toast`;
  announced via `aria-live="polite"`. Not persisted; late joiners don't see old nudges.

### Round gating
- Optional toggle "Advance rounds together" + an **Open Round N** control →
  `setGate { openRound }`. Participants blocked at the 02.1 gated notice unblock live
  on the patch. Turning gating off sends `gate: null` (free-run). Server-side reveal/
  round enforcement exists since 01.1/02.2 — this spec is the control surface.
- Gating state is visible in the drawer and echoed in participants' round interstitial.

### Spotlight control
- Wall-integrated list of revealed plaques with Spotlight/Release buttons →
  `setSpotlight(uuid | null)`; reflects live state (02.3 renders the effect). Moving
  spotlight directly from one plaque to another is one intent.

### Conclude
- "End session" (confirm Modal) → `conclude` → all participants navigate to the wall
  (decision: conclusion routes everyone to the wall; exports remain live until expiry).

## Out of scope
- Wall/spotlight rendering → **02.3**. Role assignment/creator token → **03.1**.
- Timers with countdowns → 2.1 (PRD §9).

## Acceptance criteria
- [ ] Drawer and its toggle render only for `role: 'facilitator'` — a participant
      browser has no panel affordance and hand-sent facilitator intents are rejected
      server-side (component test + party test).
- [ ] Dashboard shows live round/counts/connection for all participants and updates as
      they sort; contains no card values (two-browser E2E `e2e/facilitator.spec.ts`
      asserts text content).
- [ ] Nudge E2E: facilitator sends "2 minutes left" → banner appears on the
      participant's sort screen and auto-dismisses; screen reader announcement asserted
      via `aria-live` region in component test.
- [ ] Gating E2E: with gating on, participant finishing Round 1 is held at the gated
      notice; facilitator opens Round 2 → participant's Continue enables without
      refresh; gating off → free-run.
- [ ] Spotlight from the panel enlarges the plaque on the participant's wall; Release
      restores (extends `e2e/facilitator.spec.ts`).
- [ ] Conclude routes both browsers to the wall in `concluded` phase; sorting UI is no
      longer reachable (E2E).
- [ ] Facilitator can complete their own sort with the panel present (E2E smoke:
      facilitator sorts 3 cards mid-workflow).
- [ ] Panel fully keyboard operable; drawer focus is contained and restored
      (component test).
- [ ] `pnpm gate` green.
