## Scope

The core experience: one card at a time, swipe-first, fully local. Config-driven — one
`SortRound` renders any round; no per-step pages.

### Local store (`app/src/stores/createSortStore.ts`)
- Factory `createSortStore(sessionCode, participantId)` — Zustand store holding
  `SortState` (architecture §4.2: `round`, `queue`, `kept`, `discarded`, `lastAction?`,
  `ranking?`), persisted to localStorage key `vc:<code>:<participantId>:sort`.
  Persistence is per (session, participant); round is part of the state, not the key.
- Initialized from `config.deck` shuffled with `shared` seeded shuffle
  (seed = participantId + round → per-participant order, stable across refresh).
- Actions: `keep(cardId)`, `discard(cardId)`, `undo()` (single-level, reverses
  `lastAction` only), `demote(cardId)` (kept → back of queue). All pure updates;
  **nothing here ever touches the socket** — sorting works identically offline.

### Components (`app/src/engine-ui/`)
- `CardStack` — current card centered (GameCard `lg`), next card peeking beneath;
  deck counter.
- `SwipeCard` — Framer Motion drag x-axis: past threshold (decision: 35% of card width
  or velocity > 500px/s) commits keep (right) / discard (left) with spring exit +
  subtle rotation; under threshold springs back. Motion values read duration/spring
  tokens; reduced-motion collapses to fades via the 00.3 wrapper.
- Tap equivalents: ✗ and ✓ Buttons under the card (44px targets). Keyboard: `→` =
  keep, `←` = discard, `u`/`Ctrl+Z` = undo (decision), focus-visible ring on the card;
  actions announced via `aria-live="polite"` region ("Kept Integrity, 3 of 8").
- `KeptTray` — persistent peek bar (kept count vs round limit, e.g. "3 / 8 kept";
  "∞" hidden for keep-any rounds shows plain count) expanding to a `Sheet` grid of kept
  cards; each card has a demote action (tap/Enter). Over-limit state styles the counter
  with `--color-danger` tokens.
- `ProgressRail` — round name + position in deck (e.g. "Round 1 · 12 of 40").
- `routes/sort` — wires store + config; renders `SortRound` for `config.rounds[state.round]`.
  End-of-queue behavior (trim/advance) is 01.4; this spec ends the round at an
  end-of-deck placeholder ("Round complete") when the queue empties.

### Privacy & persistence
- Sorting emits **no network traffic** (milestone reporting arrives in 02.1). Refresh
  mid-round restores exact `queue`/`kept`/`discarded`/`lastAction`.

## Acceptance criteria
- [x] Store unit tests: keep/discard/undo/demote semantics; undo is single-level (second
      undo is a no-op); demote returns card to back of queue
      (`app/src/stores/sort-store.test.ts`).
- [x] Shuffle is deterministic per (participant, round) and differs between participants
      (unit test with two participant ids).
- [x] **Invariant 4 (progress half, PRD §6.4):** E2E `e2e/sort-refresh.spec.ts` — sort
      7 cards, reload: same next card, same kept/discarded counts.
- [x] **Invariant 1 (client half, PRD §6.1):** E2E `e2e/sort-privacy.spec.ts` records all
      WebSocket frames while sorting a full round and asserts no frame contains any card
      value or description string. (The only frame observed is Vite's dev-server HMR
      client — 01.3 opens no app socket at all — so the test asserts the card-data check
      against every frame from every socket rather than a literal zero-frame count.)
- [x] Swipe, tap, and keyboard paths each complete a keep and a discard — component tests
      (`app/src/engine-ui/swipe-card.test.tsx` for tap/keyboard) + mobile-viewport E2E
      performs touch-drag swipes (`e2e/sort-swipe.spec.ts`).
- [x] Kept tray expands, shows kept cards, demotes back to queue; counter reflects
      kept vs limit (component test + E2E).
- [x] With reduced motion emulated, card commit renders as fade — no x-translation
      (component test via motion wrapper). Verified via `swipeExitTarget()`, the pure
      function SwipeCard's commit animation calls to compute its target — exported so
      the "no x-translation when reduced" rule is deterministically unit-testable
      without depending on real animation-frame timing in jsdom.
- [x] Keyboard-only round completion: E2E completes a 12-card round using only key
      presses (`e2e/sort-keyboard.spec.ts`).
- [x] `aria-live` region announces keep/discard with running count (component test).
- [x] `pnpm gate` green (token lint included — all new UI is token-only).
