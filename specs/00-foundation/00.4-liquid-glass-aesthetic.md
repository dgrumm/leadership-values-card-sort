## Scope

Re-skin the base visual system to "liquid glass": a soft iridescent pastel field behind
everything, frosted-glass translucent surfaces, and a single card size used across every
screen. All color/blur/gradient/motion values live in `app/src/theme/` (the only dir
`token:lint` exempts); every screen keeps composing tokens, not raw values. Legibility is
guaranteed by keeping text on near-opaque panels (design decision, not per-screen tuning).

This spec supersedes the tactile-warm surface look established in 00.3 for the base
(app-wide) theme. It does **not** touch the per-session theming model (03.3 owns accent
variants / adaptive palette) — those layer on top of this base.

### Glass + iridescence tokens (`app/src/theme/tokens.css`, extends the 00.3 `@theme`)
Add to the existing `@theme` block (keep all 00.3 tokens):
- **Iridescent field** — five light pastel stops as color tokens (high luminance so `ink`
  and `ink-muted` still pass AA over any stop): `--color-iris-peach`, `--color-iris-pink`,
  `--color-iris-lilac`, `--color-iris-sky`, `--color-iris-mint`. Exact values decided in
  this file; each must be light enough that `--color-ink` ≥ 4.5:1 and `--color-ink-muted`
  ≥ 4.5:1 against it (asserted in tests below).
- **Glass surfaces** — translucent fills as color tokens (rgb with alpha, allowed in
  `theme/`): `--color-glass` (frosted panel fill, ~55% white), `--color-glass-strong`
  (~80%, for text-bearing panels), `--color-glass-edge` (top-highlight / hairline border).
- **Glass depth/blur** — `--glass-blur: 16px`; `--shadow-glass` (outer soft drop + inner
  top sheen); focus indicator `--shadow-focus` (soft light-glow ring, replaces the hard
  `outline-accent`).
- **Field motion** — `--duration-iris: 28s` and keyframes for a slow gradient drift.

`--color-surface` stays defined (export renderer + opaque fallbacks depend on it); the
app background becomes the iridescent field, applied in a `@layer base` on `body` in
`tokens.css` (or a sibling `app/src/theme/*.css`), built from the iris tokens as a
multi-stop gradient that slowly animates `background-position`. Under
`prefers-reduced-motion: reduce` the animation is removed (static gradient) — via a media
query in the theme CSS, matching the `motion.tsx` contract.

### Glass primitives (`app/src/components/`, `app/src/engine-ui/`)
- `GameCard` — frosted-glass frame: `--color-glass` fill, `--glass-blur` backdrop, hairline
  `--color-glass-edge` border, `--shadow-glass`. The **front face keeps a near-opaque panel**
  (`--color-glass-strong` or `surface-raised`) behind the value name + description so text
  contrast is guaranteed. Card back uses `accent`. 5:7 portrait retained.
- `Button`, `Modal` scrim, `Sheet`, `KeptTray`/`TrimGrid` containers adopt the glass fill +
  blur + `--shadow-glass`. Buttons keep the ≥44×44px target and token colors from 00.3.
- **Focus indicator**: everywhere 00.3 used `focus-visible:outline-2 outline-accent`
  (`SwipeCard`, `TrimGrid`, `Button`), switch to the soft `--shadow-focus` glow. Keyboard
  focus stays clearly visible (a11y gate); it just reads as glass, not a rust outline.

### One card size everywhere (`app/src/components/GameCard.tsx` + callers)
- Collapse `GameCard`'s `sm|md|lg` size variants to a **single canonical size** matching the
  main triage card (the current `lg`): width `w-[min(78vw,16rem)]` (fits 390px mobile, caps
  at 256px), `aspect-[5/7]`. Remove the `size` prop and `SIZE_CLASSES`.
- Update every caller to the prop-less card: `SwipeCard.tsx`, `CardStack.tsx`,
  `KeptTray.tsx`, `TrimGrid.tsx`, `routes/Sort.tsx` (results/deck). The Kept tray and trim
  grid now hold full-size cards — their containers **scroll/wrap** to fit (grid with
  `overflow-auto`); no card is scaled down.

### No highlight on initial deck load (`app/src/engine-ui/SwipeCard.tsx`)
- Remove the mount autofocus (`useEffect` at ~44-46 that calls `containerRef.current.focus()`).
  On first render the active card shows **no focus ring / no outline** (matches the
  attached screenshot's problem being gone). Keyboard operability is preserved: the card
  container / ✗ / ✓ remain reachable by Tab and show the `--shadow-focus` glow only when
  actually focused via keyboard.

### Showcase / tests
- `/kitchen-sink` renders the glass primitives on the iridescent field for visual + E2E
  review.
- Extend `app/src/theme/tokens.test.ts` with the new AA assertions (below).

## Out of scope
- Per-session accent variants + adaptive palette extraction → **03.3** (layers on this base).
- `RankBoard` ranked-list rows are a list interaction, not the `GameCard` grid — left as
  list rows; only their surface may pick up the glass fill, no sizing change.
- Plaque / export artifact styling → **02.3**/**04.1** (export renderer keeps opaque
  `surface`; no backdrop-blur in satori/resvg).

## Acceptance criteria
- [ ] All new tokens (`--color-iris-*`, `--color-glass*`, `--glass-blur`, `--shadow-glass`,
      `--shadow-focus`, `--duration-iris`) exist in the `@theme` block; no glass/gradient/hex
      value appears outside `app/src/theme/` — `pnpm token:lint` passes.
- [ ] `tokens.test.ts` asserts `--color-ink` and `--color-ink-muted` each ≥ 4.5:1 against
      **every** `--color-iris-*` stop and against `--color-glass-strong` composited over the
      lightest stop (worst-case text-on-panel), plus the 00.3 pairings still pass.
- [ ] `GameCard` exposes no `size` prop; renders one width (`w-[min(78vw,16rem)]`) at
      `aspect-[5/7]`; a Testing Library test asserts the single size and that all callers
      compile without a `size` prop.
- [ ] Triage, Kept tray, trim grid, and results all render the same card dimensions — E2E
      screenshot on `/sort` (or `/kitchen-sink`) at 1440px and 390px shows uniform card size;
      Kept tray/trim containers scroll rather than shrink cards.
- [ ] On initial load of the sort screen the active card has **no visible outline/ring**
      (no autofocus) — E2E asserts the container is not focused on first paint and no
      `outline`/focus ring is rendered; a keyboard Tab then shows the `--shadow-focus` glow.
- [ ] Iridescent field renders app-wide; with `prefers-reduced-motion: reduce` emulated the
      gradient is static (no animation) — E2E via `page.emulateMedia`.
- [ ] Glass surfaces use `backdrop-filter: blur(--glass-blur)`; text-bearing card face sits
      on a near-opaque panel (verified by the AA test above).
- [ ] `pnpm gate` green.
