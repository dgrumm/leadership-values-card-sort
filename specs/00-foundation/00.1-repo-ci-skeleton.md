## Scope

Stand up the monorepo-lite so every later spec lands into working gates.

### Workspace
- `pnpm-workspace.yaml` with packages `app/`, `party/`, `shared/`, `decks/`.
- Root `package.json`: `"packageManager": "pnpm@<latest 9.x>"`, `engines.node: ">=22"`,
  `.nvmrc` = `22`. pnpm only — commit `pnpm-lock.yaml`, add `.npmrc` with
  `engine-strict=true`.
- Shared strict TS base: root `tsconfig.base.json` with `strict: true`,
  `noUncheckedIndexedAccess: true`, `verbatimModuleSyntax: true` (decision: these three are
  on repo-wide); each package extends it.

### Packages
- **`app/`** — Vite + React 19 + TypeScript. Tailwind **v4** via `@tailwindcss/vite`;
  `app/src/theme/tokens.css` contains an `@theme` block with placeholder tokens (real
  tokens are 00.3) and is the single CSS entry. One route: a landing page rendering
  "Values Cards" with Start/Join buttons (non-functional links).
- **`party/`** — Cloudflare Worker + Durable Object stub using `partyserver`.
  `party/wrangler.jsonc`: DO binding `Session` (class `SessionServer`), migration tag,
  `compatibility_date` current. `pnpm --filter party dev` runs `wrangler dev` on
  Miniflare — must work with no Cloudflare account. Stub route `GET /api/health` → 200
  `{"ok":true}`.
- **`shared/`** — pure TS package (no I/O, no DOM), consumed by `app` and `party` via
  workspace protocol. Placeholder export + one passing test.
- **`decks/`** — data package: `decks/` JSON dir (empty until 00.2) and
  `decks/scripts/csv-to-json.ts` stub with CLI help text.

### Tests & gates
- **Vitest** root config with `projects` for `app`, `party`, `shared`, `decks` using
  **default include globs** (`**/*.test.ts?(x)`) — no `include`/`testMatch` whitelists,
  ever. One smoke unit test per package.
- **Playwright** at root: `playwright.config.ts` with `webServer` starting the app dev
  server; projects for desktop Chromium and mobile viewport (Pixel 7). One smoke E2E:
  landing page renders heading "Values Cards".
- **`pnpm gate`** (root script) runs, in order, failing fast:
  `tsc --noEmit` per package → `eslint .` (flat config, typescript-eslint) →
  `pnpm token:lint` → `vitest run` → `playwright test`.
- **`pnpm token:lint`** → `scripts/token-lint.mjs`: scans `app/src/**` **excluding
  `app/src/theme/**`** and fails on (a) raw Tailwind palette classes
  (`/\b(bg|text|border|ring|fill|stroke|from|via|to|shadow|outline|decoration|accent|caret|divide)-(red|orange|amber|yellow|lime|green|emerald|teal|cyan|sky|blue|indigo|violet|purple|fuchsia|pink|rose|slate|gray|zinc|neutral|stone)-\d{2,3}\b/`),
  (b) hex color literals (`/#[0-9a-fA-F]{3,8}\b/`), (c) inline z-index (`z-[` arbitrary
  values or `zIndex:` in TSX/CSS). Prints file:line for each violation.
- **`pnpm spec:status`** → `scripts/spec-status.mjs`: parses frontmatter of
  `specs/**/*.md`, validates `specs/status.json` against it (every spec present exactly
  once; `id`/`title`/`phase`/`depends_on` match; `depends_on` ids exist; statuses in
  {not-started, in-progress, done}), exits non-zero on drift, prints a status table.
  Supports `--set <id> <status>` to update the file (the only sanctioned write path).

### CI
- `.github/workflows/ci.yml`: on `pull_request` and `push` to `v2`. Steps: checkout,
  pnpm + Node 22 setup (cached store), `pnpm install --frozen-lockfile`, install
  Playwright browsers (cached), then `pnpm gate` and `pnpm spec:status`. Upload
  Playwright report artifact on failure.

## Out of scope
- Real design tokens, GameCard/Button/Modal/motion primitives → **00.3**.
- Zod schemas, game engine, bundled deck JSON content → **00.2**.
- Any Durable Object session logic beyond the stub → **01.1**.
- Deployment (Pages/Workers deploy workflows) → not in Phase 0; revisit at 04.2.

## Acceptance criteria
- [ ] `pnpm install` succeeds on Node 22 with pnpm; `npm install` is rejected
      (engine-strict).
- [ ] `pnpm gate` passes locally from a clean checkout.
- [ ] `pnpm --filter app dev` serves the landing page; `pnpm --filter party dev` starts
      Miniflare with no Cloudflare account and `GET /api/health` returns `{"ok":true}`.
- [ ] `tsc --noEmit` runs strict (`strict`, `noUncheckedIndexedAccess`) in all four
      packages and passes.
- [ ] Vitest discovers tests by default globs: adding a new `foo.test.ts` anywhere in a
      package makes it run without config changes (proved by `scripts/token-lint` and the
      four smoke tests appearing in `vitest run` output; no `include` whitelist exists in
      any vitest config).
- [ ] Playwright smoke E2E passes on desktop and mobile projects (`e2e/smoke.spec.ts`).
- [ ] `pnpm token:lint` fails when a fixture containing `bg-blue-500`, `#ff0000`, or
      `z-[999]` is placed under `app/src/` (test: `scripts/token-lint.test.ts` runs the
      linter against fixtures), and passes on `app/src/theme/tokens.css`.
- [ ] `pnpm spec:status` validates `specs/status.json` against spec frontmatter and
      exits non-zero when an id, phase, or depends_on entry is out of sync (test:
      `scripts/spec-status.test.ts`).
- [ ] CI workflow runs `pnpm gate` + `pnpm spec:status` on PRs to `v2` and blocks merge
      on failure (branch protection assumed; workflow file present and green).
- [ ] No secrets or `*_KEY` values anywhere in the repo; `.env*` is gitignored.
