## Scope

The design system as build config: tactile-warm tokens plus the four primitives every
later screen composes. All in `app/src/`.

### Tokens (`app/src/theme/tokens.css`, Tailwind v4 `@theme`)
- Colors (the only place colors exist): `--color-surface` (warm cream),
  `--color-surface-raised`, `--color-ink` (near-black warm), `--color-ink-muted`,
  `--color-accent` (terracotta), `--color-accent-hover`, `--color-accent-subtle`,
  `--color-on-accent`, `--color-danger`, `--color-success`. Exact values are a design
  decision made in this spec and recorded in the file — every default pairing used by
  primitives must pass WCAG AA (asserted with the same contrast expectations 03.3 will
  formalize; here a plain unit test with hardcoded expected ratios is sufficient).
- Scales: spacing (4px base), radius (`--radius-card` etc.), layered shadow scale
  (`--shadow-card`, `--shadow-card-lifted`, `--shadow-sheet`), z-index scale
  (`--z-base/-card/-sheet/-modal/-toast`), motion durations
  (`--duration-flip: 250ms`, `--duration-snap: 200ms`, `--duration-sheet: 300ms`) and
  spring constants exposed as CSS vars for Framer Motion to read.
- Typography: display serif **Fraunces** (self-hosted woff2 via `@fontsource`, decision —
  plan says only "serif display type"), body sans **system-ui stack**. Font-size scale
  tokens.

### Primitives (`app/src/components/`)
- `GameCard` — 5:7 portrait aspect (`aspect-[5/7]`), card-back face (theme art slot) and
  front face (value name in display serif, description beneath), sizes `sm|md|lg`,
  flip affordance prop. Pure presentational; no game logic.
- `Button` — variants `primary|secondary|ghost|danger`; minimum 44×44px touch target at
  every size; visible focus ring from tokens.
- `Modal` — focus trap (focus moves in on open, cycles, restores on close), `aria-modal`,
  `role="dialog"`, labelled by title, Esc + overlay close, scroll lock. Rendered in a
  portal at `--z-modal`.
- `Sheet`, `Toast`, `Avatar` (hue-driven: `Avatar({ name, hue })` renders initial on
  `oklch`-derived swatch) — minimal versions; consumed by 01.3/02.1.
- Motion wrapper `app/src/theme/motion.tsx` — `<MotionProvider>` resolves
  `prefers-reduced-motion` once via `useReducedMotion`; exports `useMotionSafe()` and a
  `transition` helper that collapses all springs/slides to opacity fades when reduced.

### Showcase
- Dev-only route `/kitchen-sink` rendering all primitives (used by E2E and visual review;
  excluded from any nav).

## Out of scope
- Theme variants, adaptive palette, `ThemeProvider` runtime switching → **03.3**.
- Swipe physics and card stack behavior → **01.3**; drag-to-rank → **01.4**.
- Plaque styling → **02.3**/**04.1**.

## Acceptance criteria
- [x] All token names above exist in `tokens.css` `@theme`; components reference tokens
      only — `pnpm token:lint` passes with the new components in place.
- [x] Default token pairings (ink/surface, on-accent/accent, ink-muted/surface) pass
      WCAG AA — unit test `app/src/theme/tokens.test.ts` computes contrast ratios ≥ 4.5:1
      (≥ 3:1 for large-text pairings, listed in the test).
- [x] `GameCard` renders 5:7 portrait at all sizes (Testing Library asserts aspect class;
      E2E screenshot on `/kitchen-sink` at 1440px and 390px viewports).
- [x] `Button` targets are ≥ 44×44px at every variant/size
      (`app/src/components/button.test.tsx`).
- [x] `Modal` traps focus, restores focus on close, closes on Esc, sets `aria-modal`
      (`app/src/components/modal.test.tsx` keyboard-walks the trap).
- [x] With `prefers-reduced-motion: reduce` emulated, the motion wrapper renders fades
      only — no transform animations (`app/src/theme/motion.test.tsx` +
      E2E `e2e/reduced-motion.spec.ts` using `page.emulateMedia`).
- [x] Fraunces loads self-hosted; no external font/network origin at runtime
      (E2E asserts no third-party requests on `/kitchen-sink`).
- [x] `pnpm gate` green.
