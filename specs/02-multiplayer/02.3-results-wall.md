## Scope

The shared payoff: a live gallery of revealed plaques, projector-friendly, with
spotlight.

### Plaque (`app/src/engine-ui/Plaque.tsx`)
- One revealed result: participant name + avatar, game title, that round's cards as
  mini GameCards in the session theme; ranked results show 1/2/3 order badges.
- The layout is defined as a **shared plaque layout definition**
  (`app/src/engine-ui/plaque-layout.ts`: dimensions, spacing, type scale as data)
  constrained to a satori-safe CSS subset (flexbox, no grid/filters — decision per
  architecture §12) so 04.1 renders the identical artifact. The 01.4 result-screen
  preview is refactored onto this component.

### Wall route (`routes/wall`, path `/wall/:code`)
- Reachable by every participant from sort/result screens, and the natural end state
  after `conclude`. Renders one Plaque per revealed (participant, round), grouped by
  participant, newest round shown by default with a per-plaque round switcher when a
  participant revealed multiple rounds (decision). Empty state invites reveals.
- **Live**: reveals/un-reveals appear/disappear via `patch` events without refresh.
- **Projector mode**: a full-screen toggle (Fullscreen API) hiding all chrome except
  plaques; type scale bumps for distance readability (tokens only). Works for a
  participant who has revealed nothing (viewer).
- Joining the wall of a concluded session works read-only until 24h expiry.

### Spotlight
- `setSpotlight(uuid | null)` intent (DO handling exists since 01.1): facilitator may
  spotlight any plaque's owner; a participant may spotlight **their own** plaque;
  facilitator (or the owner, for self-spotlight — decision) releases with `null`.
- Spotlit plaque enlarges to center stage on **every** connected wall view; others dim.
  `Esc` releases only if the local user is allowed to release. Reduced-motion: crossfade
  instead of scale animation.

## Out of scope
- Export buttons/rendering → **04.1** (the plaque layout contract lands here).
- Facilitator panel & spotlight drawer controls → **03.4** (a minimal spotlight
  affordance on the plaque itself ships here).
- Commonality analytics → 2.1 (PRD §9).

## Acceptance criteria
- [x] Plaque renders name, title, themed cards; ranked plaque shows order badges
      (component test `app/src/engine-ui/plaque.test.tsx`).
- [x] Plaque layout uses only the satori-safe subset — a unit test walks
      `plaque-layout.ts`/rendered styles for forbidden properties (list in test).
- [x] Two-browser E2E `e2e/wall.spec.ts`: A reveals → plaque appears on B's open wall
      without refresh; A un-reveals → it disappears.
- [x] Spotlight E2E: facilitator spotlights A's plaque → it enlarges on both browsers;
      release restores the grid. A participant can spotlight only their own plaque
      (attempt on another's is rejected — asserts error toast / disabled control).
- [x] Projector mode hides chrome and remains live (E2E toggles fullscreen and receives
      a new reveal).
- [x] Wall of a `concluded` session renders read-only (E2E: conclude, reload wall;
      server-side enforced in `shared/src/engine/apply-intent.ts`'s `setSpotlight`, not
      just a disabled client control).
- [x] Wall is responsive: 390px mobile shows single-column plaques; 1440px shows grid
      (E2E screenshots at both viewports).
- [x] Keyboard: plaques and spotlight controls reachable and operable by keyboard;
      spotlight change is announced (`aria-live`) (component test).
- [x] `pnpm gate` green.
